# Snap & Stick: Landing Page (Stage 1)

A starter landing page for an event photo magnet business.

## How to run it

No installs needed. Put all four files in one folder and double-click `index.html`. It opens in your browser. After editing a file, save it and refresh the browser tab.

## What each file does

| File | Job |
|------|-----|
| `index.html` | Structure: what content is on the page |
| `styles.css` | Looks: colors, spacing, layout, phone vs. desktop |
| `script.js` | Behavior: mobile menu, form message, footer year |

## Things to try (in this order)

1. **Rename the business.** Search for `Snap &amp; Stick` in `index.html` and replace it (there are 3 places: the tab title, the logo, and the footer). The `&amp;` is how HTML writes an `&`.
2. **Change the colors.** Edit the values at the top of `styles.css` under `:root`.
3. **Edit the pricing** cards in `index.html` to match real prices.
4. **Add a real photo.** Make a `photos` folder, add an image, and replace the hero placeholder `<div>` with an `<img>` tag (there's a hint in the comments).
5. **Test on a phone-sized screen.** In Chrome, press F12, then click the phone/tablet icon. Watch the layout change at 700px wide.
6. **Add a new section** (like "About us" or "FAQ"). Copy an existing `<section>` and restyle it.
7. **Make the form really work.** Right now it only shows a message. Look up "Formspree" or "Netlify Forms" to receive submissions by email without writing a backend.

## Goals for this stage

- Understand what HTML, CSS, and JS each do.
- Get comfortable with Flexbox (`display: flex`).
- Understand how a media query makes a page responsive.
- Know how JavaScript finds an element and reacts to a click.
